CUSTOM AUDIO ASSETS DIRECTORY
==============================

Drop your custom MP3 audio files here to override the procedural Web Audio synthesizer:

- bgm.mp3       : Looping background music (ambient cyber drone)
- correct.mp3   : Sound played on ACCESS GRANTED (correct flag/quiz)
- wrong.mp3     : Sound played on ACCESS DENIED (wrong flag/quiz)
- alarm.mp3     : Siren sound for alerts and plot twists
- unlock.mp3    : Sound played on unlocking doors or purchasing hints
- victory.mp3   : Fanfare played on Vault override & victory screen
- heartbeat.mp3 : Tension heartbeat played as trace meter approaches 100%

NOTE: If any or all of these files are missing, OPERATION BLACKOUT automatically
falls back to its built-in Web Audio API synthesizer. Zero files required!
