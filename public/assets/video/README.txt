CUSTOM VIDEO ASSETS DIRECTORY
==============================

Drop your custom MP4 video files here:

- intro.mp4     : Mission briefing video played on landing or start
- level1.mp4    : Level 1 Reconnaissance briefing
- level2.mp4    : Level 2 Web Security briefing
- level3.mp4    : Level 3 Cryptography briefing
- level4.mp4    : Level 4 Malware Hunter briefing
- vault.mp4     : Final Vault victory animation

NOTE: If these files are not present, the game uses high-performance CSS and canvas
terminal simulations with a built-in Skip button, muted-by-default on mobile (playsinline).
